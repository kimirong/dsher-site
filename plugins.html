How to install

如何安装

安装到默认 profile

$ dsh plugin add <包名>

从 npm 安装插件包（bundle）。示例：dsh plugin add @deepseek-ai/dsh-web-app

从 GitHub 安装

$ dsh plugin add github:<owner>/<repo>

无需发布到 npm，直接从仓库安装。建议固定提交：github:owner/repo#<sha>

命名 profile

$ dsh plugin --profile <名字> add <包名>

安装到指定 profile；首次使用会自动初始化（以 @deepseek-ai/dsh-base 为第一层）。

Git 安装须知：从 Git 安装的是源码而非构建产物，仓库需提供 prepare 脚本；pnpm ≥10 会要求先在 profile 的 pnpm-workspace.yaml 中允许该包的构建（allowBuilds）。

安全提示：安装会执行包代码，请只允许你信任的来源，并固定 commit。

完整机制见官方文档：Package and install a plugin
