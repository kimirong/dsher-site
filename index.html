What is dsh

什么是 dsh？

dsh 是 DeepSeek Harness 的缩写——DeepSeek AI 开源的 agent harness（智能体运行框架）。它采用「一切皆插件」的架构，构建在 Cordis 之上：会话、工具、模型接入、Web UI……整个运行时都由可插拔的组件组装而成。

目前 dsh 处于开发者预览阶段，迭代非常快，官方明确提示会有破坏性变更——但这正是玩它的乐趣所在。

为什么叫 dsher？

dsh + er —— 就像 hacker 之于 hack，dsher 就是「玩 dsh 的人」：写插件的人、调 agent 的人、把想法装进 harness 的人。

注册这个域名，是想给这群人一个落脚点。不用申请，不用审核——跑起来的那一刻，你就是 dsher。

Why dsh

为什么值得玩

🧩

一切皆插件

基于 Cordis 的插件化架构，从 agent 循环到 UI 全部可组装、可替换、可自修改。

🖥️

多形态入口

Web UI、CLI、ACP 自动化服务器、JSON-RPC 服务端——同一个 harness，多种玩法。

🧠

LLM 能力层

Service Definition / Consumer 的能力抽象 + DeepSeek 官方 providers，模型接入干净利落。

🛠️

工具全家桶

bash/shell、子进程、文件系统与策略、LSP、Web 搜索抓取、技能（skills）开箱即用。

👥

多智能体协作

subagents 委托、workflow 编排、todo 与计划模式，把复杂任务拆给一群 agent。

📜

会话持久化

模型可见的一切都可从会话日志重建——断点续跑、回溯、复现，全程可审计。

🔒

安全与审批

交互式审批、权限控制、文件系统策略与沙箱，让 agent 放开手脚又不失控。

♻️

自我进化

agent 能检查并挂载自己的插件——它不只是跑在 harness 里，它就是你写的 harness。

Get started

一分钟成为 dsher

需要：Node.js
$ npx @deepseek-ai/dsh web
# 默认打开 http://127.0.0.1:3080 的 Web UI 🎉
需要：Node.js + pnpm
$ git clone https://github.com/deepseek-ai/deepseek-harness.git
$ cd deepseek-harness
$ pnpm install
$ pnpm run build
$ pnpm dsh web

更多玩法见官方文档：github.com/deepseek-ai/deepseek-harness
